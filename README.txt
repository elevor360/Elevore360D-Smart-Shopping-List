Elevore360D Smart Shopping List — V1.0

UPLOAD TO GITHUB PAGES
1. Create a public GitHub repository (for example Elevore360D-Smart-Shopping-List).
2. Upload ALL files from this ZIP to the ROOT of the repository (not inside a folder).
3. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
5. On Android Chrome, use Install App when offered, or Chrome menu > Add to Home screen / Install app.

V1 FEATURES
- Multiple shopping lists, create/rename/delete
- Add, edit, tick and remove shopping items
- Auto-save on this device, offline-ready
- Installable PWA with a version badge

IMPORTANT
- No loyalty wallet or advertisements yet; these are planned for V2 and V4.
- Data is stored in the browser on each device, not synced between devices.
- Clearing site data can erase lists; backup/restore is planned for V3.
- Version badge will be removed in V5 final release.
